# Vacuula - formerly Brainslug
Undead robot vacuum cleaners *you* control and own!

> [!NOTE]
> ### Vacuula 1.0 has been released! 🎉
> After lots of hard work the first release of Vacuula has arrived! You can now restore your artificially dumbed-down Neato vacuum cleaner to<sup>past?</sup> it's former glory __without needing to use an esp32__! Vacuula can be installed *directly* on the robot, no hardware modifications required!
> 
> Area cleans, no-go lines & zones, scheduled runs, cleaning mode, *correct* maps and cleaned area etc. are all supported!

So go set up a [server](/vacuula/vacuula), then use the [installer](/vacuula/installer) to *bite* your robot and bask in the knowledge that now ***you*** control the lifetime of what you bought!

Don't have a neato robot? Let's just say they (for reasons that might or might not be called *arbitrary deprecation*) are really cheap on the second hand market right now.


*\* If you decide to buy a second hand neato, check that it actually runs in the dumb mode. The robots can be in a soft-bricked state which is varyingly difficult to fix and probably requires additional hardware (TTL-usb converter)*  
*\* Be confident you can set up the server before you buy anything!*
